# Omnitone

Sampler e sintetizador gratuito para Windows, com até 8 camadas, splits, síntese FM, órgão de tonewheels, sintetizador analógico virtual, SFZ e SoundFont. Aplicativo e plugin VST3.

**Página e download:** https://helicleiton.github.io/Omnitone/

- [Baixar o instalador](https://github.com/helicleiton/Omnitone/releases/latest/download/Omnitone-Setup.exe)
- [Versão portátil (zip)](https://github.com/helicleiton/Omnitone/releases/latest/download/Omnitone-win64.zip)

O Omnitone é gratuito e sempre será.

## Problemas e sugestões

Abra um relato em [Issues](https://github.com/helicleiton/Omnitone/issues) informando a versão do Windows, a interface de áudio e o que aconteceu. O roteiro de testes está em [TESTES.md](TESTES.md).
